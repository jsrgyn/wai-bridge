# Visão do projeto

WAI Bridge (Local WhatsApp AI Integration Bridge) é planejado como sistema local para observar novidades acessíveis do WhatsApp Web, persistir estado local e expor capacidades controladas a agentes de IA via MCP. O desenho inclui extensão Chrome, agente macOS intermediário, API REST local, SQLite, filesystem de mídias e notificações WebSocket.

O objetivo desta fase é documentar regras e contexto. A estrutura existente é bootstrap: não há integração WhatsApp, envio, API funcional ou regras de negócio implementadas. Consulte `docs/requirements/` e `.ai/rules/` como requisitos futuros, não como evidência de implementação.
