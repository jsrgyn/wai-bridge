# Registros de decisão arquitetural (ADR)

Registre aqui decisões que afetem limites de módulos, fluxos, segurança, persistência, contratos ou tecnologias. Use arquivos sequenciais, por exemplo `0001-local-api-boundary.md`.

Cada ADR deve incluir: título, data, status (`Proposed`, `Accepted`, `Superseded`), contexto, decisão, alternativas consideradas e consequências. Decisões aceitas não substituem a atualização dos documentos de regras/contexto correspondentes.
